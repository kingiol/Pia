## 风险升级规则

- 极高影响风险必须有自动阻断；
- 高影响风险必须有负责人和回滚方案；
- 连续两周未下降的高风险必须进入周会决策；
- 发生真实数据或交易事故时，暂停相关 Agent 能力，优先保留只读和审计。
