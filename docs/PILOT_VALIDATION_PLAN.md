# Pia Pilot Validation Plan

## 目标

验证有经验的 A 股个人投资者是否愿意持续使用 Pia 来检查持仓、遵守投资规则和复盘决策。

本轮试点验证产品价值，不验证预测收益，也不验证自动交易。

## 目标用户

优先招募 10–15 位用户，每位至少满足以下三项：

- 已经持有 A 股或 ETF；
- 有自己的选股、仓位或止损方法；
- 目前使用同花顺、东方财富、Excel、Notion 或手工记录做研究；
- 每周至少愿意花 1 小时复盘；
- 能够具体指出研究结果哪里有用、哪里不可信。

暂不把高频交易者、完全没有投资方法的新手和需要团队协作的机构用户作为本轮样本。

## 统一测试任务

每位用户完成同一条路径：

```text
配置投资方式
-> 导入持仓
-> 设置一条个人规则
-> 完成一次收盘复盘
-> 打开至少两条证据
-> 查看一条风险门禁
-> 选择人工动作
-> 记录实际操作或不操作的原因
```

任务使用明确标注的 replay data 或当天可验证的 live data。不能让用户把合成数据误认为实时行情。

## 观察指标

| 指标 | 计算方式 | 通过门槛 |
|---|---|---|
| First-value completion | 完成首次研究任务的用户数 / 注册用户数 | >= 70% |
| Time to first value | 从进入工作台到保存第一份研究的时间 | 中位数 <= 10 分钟 |
| Evidence comprehension | 能在 2 分钟内指出结论证据和规则结果的用户比例 | >= 80% |
| Useful alert rate | 用户标记为有用的提醒 / 已查看提醒 | >= 50% |
| Weekly return | 第二周仍查看研究或事件的用户比例 | >= 40% |
| Decision journal completion | 至少记录一次实际动作或不操作原因的用户比例 | >= 50% |
| Purchase intent | 明确愿意付费或参加付费试用的用户比例 | >= 20% |

这些是试点门槛，不是市场规模预测。

## 访谈问题

首次使用后询问：

1. 你认为 Pia 帮你完成了哪一项原本会自己做的工作？
2. 哪一条证据或风险门禁改变了你的判断？
3. 哪个提醒应该出现，哪个提醒可以忽略？
4. 你是否相信这次研究结果？为什么？
5. 你希望 Pia 记住哪些投资习惯或规则？
6. 如果每周持续监控你的持仓，你愿意支付什么价格区间？

避免询问“你喜欢这个产品吗”这类无法指导决策的问题。

## 继续条件

达到以下条件后，继续强化 Personal Investment Operating System：

- First-value completion >= 70%；
- Useful alert rate >= 50%；
- 至少 5 位用户完成两周使用；
- 至少 3 位用户主动要求继续使用或询问付费。

## 调整条件

如果用户愿意研究但不愿意持续回来，优先调整事件触发、提醒频率和复盘入口。

如果用户查看证据但不信任结论，优先修复数据来源、时间点、失效条件和研究表达。

如果用户只把 Pia 当成选股问答工具，说明当前定位表达不够清楚，应收窄功能入口并强化规则、持仓和复盘路径。

## 停止或转向条件

如果 10 位以上目标用户都无法在 10 分钟内完成首次研究，或者没有用户愿意留下持仓和规则上下文，应暂停新增功能，重新检查核心问题和目标用户。
